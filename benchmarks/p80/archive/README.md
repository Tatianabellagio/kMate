# p80/archive/

Superseded p80 simulation sets. Not consumed by anything — the live sims are in
`../sims/`.

| dir | what it is |
|---|---|
| `sims_buggy_preFix_2026-06-18/` | six regimes set aside when the simulation was fixed and regenerated on 2026-06-18. **The specific defect is not recorded** in git history or any doc — the dir name is the whole provenance. See `../../p231/archive/README.md`, same event. |
| `sims_raw/` | 2026-05-22 `*_raw_p80_chr1` sims, superseded by the `hotspots_*` recombination-map regimes the benchmark now uses throughout. |

Any benchmark number computed before 2026-06-18 used the buggy sims. Truth tables are
the yardstick every arm is scored against, so a pre-06-18 number is not comparable to
a post-06-18 one even for the same estimator.
