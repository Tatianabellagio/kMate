# Session 2026-06-29 — confidence on ĥ + global-free window mode

Investigation log for the "how certain is the founder mixture ĥ, and where does that
certainty break down" work. Two threads: (1) a global-free `--local-only` window mode
that NaN's low-evidence windows instead of borrowing global h; (2) quantifying the
error/uncertainty on ĥ and decomposing it into coverage vs identifiability.

**Headline finding:** the error in ĥ is dominated by **identifiability / collinearity
bias**, not sampling variance. In **global** mode it is *coverage-independent* (same at
3× and at infinite coverage); in **window** mode it is ~3.5× larger and *does* respond
to coverage (through local k-mer support). Variance-based SEs (Fisher, parametric
bootstrap) cannot see this bias — the parametric bootstrap's nominal 95% interval
covered the truth only 6% of the time.

---

## Thread 1 — global-free `--local-only` window mode (code, landed)

**Goal.** In window mode, low-evidence windows currently fall back to the chromosome
global h. We want an option that instead reports **NaN** (no local evidence), so the
output honestly flags where there is no local information rather than silently
borrowing global signal.

**Change.** New flag `--local-only` on `kmate run` / `per_sample_per_chrom.py`
(requires `--block-mode window`):
- forces `--global-anchor-weight 0` (no anchor toward global h),
- windows below `--min-kmers-per-block` (default 200 **nonzero-count** k-mers), empty
  windows, and unassigned records → **NaN** AF (no global_h leak). All three leak
  points plugged: `block_em.py` per-block fill (`fallback_h = NaN`), the projection
  fallback, and unassigned records.
- Production window mode unchanged (flag defaults off).

Files: `src/kmate/per_sample_per_chrom.py` (`--local-only`, `min_kmers_per_block`,
`proj_fallback_h`), `src/kmate/block_em.py` (`local_only`, `fallback_h`).

**Smoke test — job 35270490** (g3 recombinant pool, 10 kb, min-kmers 200):
- `--local-only`: 371,095 NaN AF (**18.1%** of records) — records in low-evidence /
  empty windows, honestly flagged.
- anchored (production): **0** NaN (every record falls back to global).
- Well-resolved windows agree (finite-AF means 0.1178 vs 0.1146).
- ⇒ at 10 kb / min-kmers 200, ~13% of windows fall below the floor → covering ~18% of
  records. Consistent with most 10 kb windows being k-mer-starved.

## Thread 2 — confidence / error on ĥ

### 2.0 The uncertainty module (`src/kmate/h_uncertainty.py`, new)
Implements, for validation/benchmarking (not yet wired into the driver):
- `fisher_cov_h` — analytic covariance from the observed Fisher information
  `J = K diag(ω_k c_k / μ_k²) Kᵀ`, pseudo-inverted on the simplex tangent space over
  the estimated support. Tunables `support_eps`, `rcond`.
- `bootstrap_cov_h` — parametric Poisson bootstrap (`c* ~ Poisson(λ̂ μ_k(ĥ))`, refit);
  pass `rate_h=h_true` for the gold truth-MC sampling distribution.
- `identifiability` — per-region effective rank + condition number of J_SS.
- `af_se_from_cov` — delta-method propagation of Σ to the AF functional
  `AF_r = ĥᵀv_r/ĥᵀu_r`, `g_r = (v_r − AF_r u_r)/(ĥᵀu_r)`, `Var = g_rᵀ Σ g_r`.

### 2.1 Fixture validation (F=5)
- Bootstrap ≈ truth Monte-Carlo (gold confirmed).
- Naive Fisher SE off 10–20× for low-mass/collinear founders (simplex-boundary
  breakdown; support Fisher info catastrophically ill-conditioned).
- Salvageable: `support_eps=1e-3` + `rcond=1e-2` → Fisher tracks bootstrap (corr 0.98,
  median ratio 1.02). But the right rcond is data-dependent → motivated the p80 bench.

### 2.2 Fisher-vs-bootstrap on p80 — job 35271703 (`bench_h_uncertainty.py`)
Clean generative test (counts `~ Poisson(λ μ(h_true))`), F=80, real n50 weights, ω=1/m_b.
- **cov 3:** bootstrap matches truth-MC in *spread* (corr 0.918), **but the nominal
  95% interval covers h_true only 6%**, and `‖ĥ−h_true‖ = 0.048` (≈ unchanged at cov10).
- ⇒ The "gold" parametric bootstrap is badly **anti-conservative** — it measures
  scatter around ĥ, but the error is a **bias**. This (not Fisher's quirks) is the real
  problem, and it pointed straight at the convergence/identifiability question below.
- (Job was still running at session end; its calibration table is now confirmatory.)

### 2.3 GLOBAL convergence/bias diagnostic — job 35275967 (`diag_convergence.py`)
Decompose error into under-iteration / float32 / identifiability, sweep coverage incl.
**noiseless** (`c_k = μ_k(h_true)`, coverage = ∞). p80, whole Chr1 (8.1M k-mers).

| coverage | ‖ĥ−h_true‖₂ |
|---|---|
| ∞ (noiseless) | 0.0485 (f32) / 0.0485 (f64) |
| 3× | 0.0485 |
| 10× | 0.0482 / 0.0485 |
| 30× | 0.0488 |

- **Not coverage** — flat from 3× to infinite coverage.
- **Not float32** — f32 ≡ f64.
- **Not under-iteration** — ‖Δh‖ plateaus ~1e-6 by iter 2000; the `converged=False`
  flag is **cosmetic** (production `tol=1e-7` on an 80-vector is below the reachable
  float floor, so the loop always runs to max_iter after ĥ stopped moving).
  *Actionable: relax production tol or use a value-stability stop to save iterations.*
- **It is identifiability bias** — ĥ leaks ~1.3% mass onto absent founders (n̂_supp 52
  vs true 50); most error is mis-apportionment among collinear *present* founders.

### 2.4 WINDOW convergence/bias diagnostic — job 35277452 (`diag_window.py`)
Same generative test per 10 kb window (g0 ⇒ per-window truth = global h_true), p80,
3043 windows, 3 Poisson reps/coverage.

| condition | median ‖ĥ_w−h_true‖₂ |
|---|---|
| noiseless (∞) | **0.167** |
| 3× | 0.174 |
| 10× | 0.169 |
| 30× | 0.167 |
| **global ref** | **0.0485** |

Coverage effect on windows ≥200 k-mers (identifiability subtracted): +0.007 (3×),
+0.002 (10×), +0.001 (30×). `corr(log10 n_kmers, err) = −0.686`. 5% of windows below
the 200-k-mer floor.

- **Per-window h ~3.5× less identifiable than global** (0.167 vs 0.0485), 99% of windows
  > 0.1, even at infinite coverage — few thousand local k-mers can't pin 80 founders.
- **Coverage matters here (unlike global)** — monotone inflation as depth drops, via
  **support collapse** (low λ → window k-mers get zero counts → less effective support).
  This is the mechanism behind NaN'ing low-info windows (Thread 1).
- **Local k-mer support is the dominant lever** (corr −0.69).

## Synthesis & implications

1. **Per-founder ĥ is not identifiable** (global bias 0.0485; per-window 0.167),
   regardless of coverage/precision/iterations. Matches `BACKGROUND.md` limitation #4
   ("per-ecotype recovery noisy; aggregates accurate").
2. **Variance-based SEs (Fisher, parametric bootstrap) cannot capture this** — they
   describe scatter around ĥ, not the bias. Hence the 6% coverage of 95% bootstrap CIs.
   An honest per-window confidence must encode **local identifiability** (k-mer support,
   founder resolvability / Fisher condition number), not just depth.
3. **Global vs window:** global pools chromosome-wide evidence ⇒ coverage-independent
   and well-determined; window trades that for local resolution ⇒ worse identifiability
   and coverage-sensitive. The `--local-only` NaN'ing is the qualitative flag; a
   support/identifiability score would be its quantitative companion.
4. **The reportable, identifiable quantity is the AF functional** `AF_r = ĥᵀv_r/ĥᵀu_r`
   (sums over carriers; robust to AF-neutral founder swaps in the non-identifiable
   subspace) — consistent with the 0.008 headline AF MAE.

## Update 2026-06-29 (cont.) — verification + the certainty framework

**Fisher-vs-bootstrap benchmark finished (job 35277887, p80 F=80).** Confirms §2.2:
`‖ĥ−h_true‖` = 0.0477/0.0479/0.0478 at cov 5/10/30 (flat = bias); bootstrap 95% CI
covers truth **3–8%**; Fisher SE corr to bootstrap only ~0.74–0.79 and ~**8× larger**
(they disagree); support eff_rank ≈ **20 of 62** founders (cond ~722) — a real
collinear null-space. ⇒ in **global mode neither Fisher nor bootstrap is a usable
certainty**; the honest statement is the identifiability one (eff_rank/null-space).

**EM fixed-point audit — my "estimator-bias, not non-identifiability" hypothesis was
REFUTED (decisive one-step test, p80).** `a_f = Σ_k ω_k K_fk` has CoV **1.6%**
(max/min 1.08) → `||EMstep(h_true)−h_true|| = 0.0023`, exactly the predicted `h∝h_true·a_f`
tilt, while `PNMFstep` (per-founder normalization) is an exact fixed point (0.0000).
So the normalized-EM bias is real but only **0.0023 of the 0.0485** floor (~5%): `h_true`
is *nearly* a fixed point yet the EM lands 0.0485 away ⇒ a **near-flat manifold of
near-optima ⇒ genuine non-identifiability dominates.** The doc's "identifiability bias"
framing stands. (Caveat checked on the 231 production panel — job 35279008: `a_f` CoV = 0.021
(vs p80 0.016), one-step residual 0.0035 (vs 0.0023). Marginally larger — ω
equalizes the heterogeneous panel nearly as well — so non-identifiability still
dominates on production; the normalization slice stays a small add-on.)

**HARP (Kessner 2013) prior art.** HARP *does* compute an SE — observed information
`I=−d²L(f̂)` inverted on the simplex tangent space via an orthogonal-`W` reparametrization
(Lange 2010) = **exactly our `fisher_cov_h`**. hapFIRE discards it (parses only point
`.freqs`; its cvxpy founder solve + cross-block average emit no SE). HARP's regime
(*Drosophila*, 162 divergent haplotypes, ~10 SNPs/read) is well-conditioned and
bias-negligible — neither holds for 231 collinear *Arabidopsis* founders. So the
canonical SE is the **necessary-but-insufficient** one our results expose.

**The certainty framework (the synthesis).** ĥ error = two orthogonal components, and
the *mode* sets which dominates:
| component | what it is | predictor | global | window |
|---|---|---|---|---|
| **identifiability / resolvability** | which founders the available k-mers can separate (flat-manifold dirs) | **eigenstructure of J** (eff_rank, cond, null-vecs) — NOT an SE | dominant (the 0.0485 bias) | worse per-window |
| **sampling variance** | finite reads → noisy counts → noisy ĥ | **Fisher SE / bootstrap**, scaled by counts | negligible (8M k-mers over-determine) | first-order (support collapse, corr −0.69) |

The unifying object is the **(local) Fisher information `J = K diag(ωc/μ²) Kᵀ`**: its
*spectrum* gives identifiability, its *scale* gives variance. ⇒ **Global mode:** report a
resolvability diagnostic (eff_rank / confounded-founder groups), not an SE. **Window
mode:** report a per-window Fisher SE (variance, tracks coverage+support) *plus* per-window
eff_rank/cond (local identifiability) — validated by window/block bootstrap (the
correlation-respecting gold, = hapFIRE's discarded per-block jackknife). Window-mode
calibration test launched: job 35279009 (`window_certainty.py`).

## Window-mode certainty result (job 35279009, `window_certainty.py`, p80 n=2734 windows)

```
identifiability — predicting the per-window noiseless floor:
  corr(n_local_truefounders, floor) = -0.44   corr(log10 n_kmers, floor) = -0.42
  corr(eff_rank, floor) = -0.09 (WEAK)         corr(log10 cond, floor) = -0.22
variance — per-window Fisher 95% interval coverage of truth:
  cov 3: 0.96   cov 10: 0.91   cov 30: 0.79
  corr(FisherSE, coverage-excess) ~ 0.00 (non-discriminative)
  Fisher vs window-bootstrap SE: corr 0.31, Fisher 7.6x larger
  (GLOBAL ref: bootstrap 95% cover ~ 0.06)
```

**Directionally confirms the framework but with caveats.** Window mode IS better for a
variance certainty — per-window Fisher 95% intervals cover truth **91–96% at cov 3–10**
(cohort regime) vs global's **6%**. BUT: (1) it's "wide intervals from sparse local data,"
not principled bias/variance separation — at cov 30 coverage falls to **0.79** as the SE
shrinks below the persistent per-window non-identifiability bias; (2) Fisher SE is
**non-discriminative** (corr ~0 with which windows are worse) and **7.6× larger than the
(per-k-mer) bootstrap** — same ~8× gap as global, unresolved because both methods assume
k-mer independence; (3) the **Fisher eigenstructure is a weak floor predictor** (eff_rank
r −0.09) — plain **local support** (`n_local_truefounders` / `n_kmers`, r −0.43) is the
best and cheapest.

**Final recommendation — how to estimate certainty of ĥ:**
- **Global:** resolvability diagnostic (eff_rank, confounded-founder groups). No SE.
- **Window / `--local-only`:** per-window **Fisher SE** (HARP-canonical; truth-calibrated
  ~0.91 at 10×) + **local k-mer support** as the primary discriminative flag + **flag
  high-coverage windows** where bias re-emerges.
- **Open validation:** a true **block/bubble bootstrap** (resample bubbles) to resolve the
  7.6× Fisher-vs-bootstrap gap before trusting absolute SEs (k-mers within a bubble are
  correlated → per-k-mer methods anti-conservative).

## Update 2026-06-30 — the two-metric test, CRLB verdict, and the reporting decision

**Question (from TB):** split the ĥ error into (1) a coverage/variance metric and (2) a
panel-complexity / collinearity (resolvability) metric, one each, reportable in BOTH
modes. Built `metric_prototype.py` (jobs 35282581/35282588) to find the right statistic
for each, validated against the targets already in `window_certainty.tsv` (err_noiseless
= resolvability target; coverage_excess = err_cov−err_noiseless = variance target). No EM
reruns — only deterministic panel quantities.

**Result — the clean two-metric design does NOT deliver a usable per-estimate error on h:**

*(A) Resolvability (window).* The floor (0.167) is genuine under-determination, NOT missing
data — in 97% of windows all 50 founders are locally present yet the floor persists. But
**no collinearity/identifiability statistic predicts it**:
| candidate | corr vs err_noiseless |
|---|---|
| local k-mer supply (n_kmers / ndist) | −0.37 / −0.42 (log) — best, but weak |
| nfnd_present (founders seen locally) | −0.44 / −0.50 (log) |
| distinct founder signatures (nsig) | −0.21 |
| ω-Gram eff_rank | **+0.18 (wrong sign)** |
| count-weighted Fisher eff_rank (old) | −0.09 |
| **CRLB √trace(J⁺) — the principled predictor** | **−0.035 (≈0), all rcond** |

Multivariate R²=0.375 — the per-window floor is only weakly summarizable by any scalar.
The CRLB is the smoking gun: it is **not** degenerate (varies, median ~1–4) but blows up to
**1.7×10⁶** on the collinear/flat directions, exactly where the real error stays bounded
(0.12–0.24). Mechanism: the multiplicative EM **regularizes** the flat likelihood manifold
to a **biased but bounded** fixed point; variance theory (Fisher/bootstrap/CRLB) describes
the **unbounded variance** the EM never exhibits. So variance metrics measure the wrong
object — huge where error is small, silent where the bias actually is. Holds in BOTH modes.

*(B) Coverage (window).* Negligible (+0.007 at 3× vs 0.167 floor) and unpredictable — Fisher
SE, nzk, and the analytic realized-support metric all corr ≈0 with coverage_excess. No
useful separate per-window variance metric in the 3–30× regime.

*Global.* The 0.0485 floor is a real collinearity null-space (Fisher eff_rank ~20/62), made
coverage-independent by pooling 8M k-mers. (Aside: the pure-ω Gram eff_rank, 2.7, is the
WRONG weighting vs the meaningful ω/μ Fisher's ~20 — the `1/μ` up-weighting of rare
distinguishing k-mers is load-bearing.)

**Why HARP computes an h Fisher SE and we don't (no contradiction).** The observed-info SE
= error only when the MLE is interior, the Hessian well-conditioned, and bias negligible.
HARP's regime (Drosophila, 162 *divergent* haplotypes, ~10 SNPs/read) satisfies all three →
variance = error → SE is correct & calibrated. Ours (80–231 *collinear* founders) violates
all three → near-singular Hessian (the CRLB 10⁶ blow-up) + EM-regularized biased ridge →
variance ≠ error. Same formula, regime-dependent validity. Direct proof: our parametric
bootstrap (HARP-consistent gold variance) covers truth 6%, and error is flat 3×→∞. HARP
never tested a collinear regime, so their having an SE isn't evidence it's calibrated here.

**Bottom-line reporting decision (what kMate should emit):**
1. **Certify the AF functional, not h.** `AF_r = ĥᵀv_r/ĥᵀu_r` sums over carriers ⇒ swaps
   within the flat manifold cancel ⇒ the dominant h-bias largely cancels. AF is the
   identifiable quantity (the 0.008 MAE headline), where variance dominates and the Fisher
   delta-method SE (`af_se_from_cov`) should be calibrated. **Validating now: job 35282626
   (`af_certainty.py`)** — does the h-bias cancel in AF, and does the Fisher AF-SE cover
   truth ~95% (vs h's 6%)? Gate for wiring into the driver.
2. **For h itself, report a resolvability statement, never an SE.** Global: eff_rank /
   confounded-founder groups (Fisher null-space). Window/`--local-only`: local k-mer support
   flag + NaN below floor (already built). The honest analog of HARP's SE for a collinear
   panel.

Paper line: *"kMate reports calibrated uncertainty on the identifiable allele-frequency
functional (per-record delta-method SE); the latent founder mixture ĥ is only partially
identifiable (as in any collinear-panel mixture, cf. HARP) and we report a resolvability
diagnostic rather than an over-confident per-founder SE — a refinement HARP's well-
conditioned regime never needed and hapFIRE discards."*

New artifacts: `metric_prototype.py` (+ `results/metric_prototype_windows.tsv`),
`af_certainty.py` (+ `run_*.sbatch`). Jobs: 35282581/35282588 (metric+CRLB), 35282626 (AF).

## Update 2026-06-30 (cont.) — AF certainty validated, calibrated, and WIRED IN

**AF validation (job 35282626, `af_certainty.py`, p80 Chr1 global).** The h-bias only
PARTIALLY cancels in AF: h bias 0.0485 → AF bias **0.0102** (5×, ratio 0.21), not zero.
AF error stays bias-dominated (MAE flat 0.0101 across cov 3/10/30; cov-excess ≈0), so the
pure-variance Fisher AF-SE is NOT a calibrated CI — its 95% interval covers truth only
**0.32 / 0.18 / 0.13** at cov 3/10/30 (shrinks as SE drops below the fixed bias floor).
BUT the Fisher AF-SE IS discriminative (**corr(SE,|err|)=0.60** vs ≈0 for h). Bonus: the
0.010 noiseless floor ≈ the whole 0.008 AF MAE ⇒ kMate AF accuracy is **identifiability-
limited, not coverage-limited** at these depths.

**Decision (TB): calibrated total SE** `SE_total = √(SE_Fisher² + c²)`, c = benchmarked
panel identifiability floor.

**Calibration (`af_calibrate_floor.py`, jobs 35282740 p80 / 35282741 231; closed-loop g0,
binary-search c for 95% coverage):**
| panel | c (well-called) | c (all defined) | well-called frac |
|---|---|---|---|
| p80 | 0.0179 | ~0.018 | 86% |
| **231 (production)** | 0.0102 | **0.0186** | **33%** |
Chose **c=0.0186** (231 all-defined) as `AF_ID_FLOOR_DEFAULT`: only 33% of 231 records are
well-called, so the other 67% (cactus-only SVs etc.) carry larger bias and need the higher
floor — calibrating to well-called would under-cover two-thirds of records incl. the SVs.
p80 (0.018) ≈ 231-all-defined (0.0186) ⇒ the floor is a stable panel property (~0.018).

**WIRED into `per_sample_per_chrom.py` (global mode, opt-in `--emit-af-se`):**
- after the EM (k-mer matrix still alive) compute the observed Fisher info → `Σ` and the
  h-resolvability diagnostic (eff_rank/cond), chunked Fisher for the 231 panel
  (`fisher_information_h(..., chunk=1e6)`, byte-equivalent to unchunked).
- per record: `se` column becomes `√(af_se_from_cov² + c²)` (chunked over records); the
  legacy binomial `se` stays when the flag is off (production byte-identical).
- `--af-id-floor` (default 0.0186) overrides c; resolvability (eff_rank/cond/support_size)
  stored per chrom in the `.h_per_chrom.npz`.
- Verified: `kmate selftest` still PASS (R²=0.966, flag off); `--emit-af-se` on the fixture
  → se 100% finite, floored at 0.0186, eff_rank/cond emitted; chunked≡unchunked Fisher.
