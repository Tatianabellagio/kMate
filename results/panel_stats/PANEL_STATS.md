# Production panel statistics (arch3, 231 founders) — for the paper

Generated by `scripts/panel_stats_for_paper.py`. SV cutoff = length change > 50 bp.

Panel: **231 founders** (78 cactus + 153 PanGenie assemblies), 5 chromosomes (TAIR10).

**Headline:** the panel is **segregating-only by construction** — **8,489,646** biallelic
records, all with 0 < AC < AN. Monomorphic records (ALT carried by no founder, or by all
called founders) are removed at panel creation by the `jobA4` Step-3 filter
`bcftools view -e 'INFO/AC=0 || INFO/AC=INFO/AN'` (see §8). The k-mer panel that drives
kMate (K_pa) holds **42,250,364** k-mers and is likewise free of singletons and invariants.

## 8. Invariant-site audit (post-filter) — VCF vs V_pa

The panel is filtered to segregating sites at creation (`jobA4` Step 3). Re-audit of the
regenerated panel confirms **0 monomorphic records remain**, and the VCF and matrix agree
exactly (validation that V_pa encodes the VCF faithfully):

| | records | AC=0 | AC=AN (>0) | AN=0 |
|---|--:|--:|--:|--:|
| V_pa (matrix) | 8,489,646 | 0 | 0 | 0 |
| VCF (INFO/AC,AN) | 8,489,646 | 0 | 0 | 0 |

- Before this filter the catalog held 10,325,364 records, of which **1,835,718 (17.78%)
  were monomorphic** — almost entirely AC=0 (ALT carried by no founder). Of those AC=0
  rows, ~192k (Chr1 alone) were fully-called all-REF: alleles present in the pangenome
  graph but traversed by no panel founder; the rest had carriers removed by the haploid
  genotype QC (het/conflict → `.`). All are now excluded.
- **K_pa** carries no invariants/singletons either (founders-per-k-mer ∈ [2, 230]; §6).

## 9. Reproducibility — exact commands for each statistic

Env: `PY=/global/home/users/tbellg/miniforge3/envs/kmate/bin/python`,
`BCF=/global/home/users/tbellg/miniforge3/envs/kmate/bin/bcftools`. Paths below use

```bash

```

Per-statistic detail (what each script runs):

**§1 — file sizes & record counts**
```bash
du -m panel/arch3/${cl}/merged_231_${cl}_final.vcf.gz           # VCF size (MB)
$BCF index -n panel/arch3/${cl}/merged_231_${cl}_final.vcf.gz   # VCF record count
# matrix set sizes = os.path.getsize() of {var_pa,var_called,meta}.npz and {kmer_pa,meta}.npz
# k-mers / bubbles = len(kmer_index) / len(bubble_start) in the K_pa meta.npz
```

**§2/§3 — variant classes & SV size spectrum** (from V_pa meta `ref_len`,`alt_len`)
```python
m = np.load(f"panel/arch3/{cl}/var_pa_231_arch3_{cl}.meta.npz", allow_pickle=True)
rl, al = m["ref_len"], m["alt_len"]; Ldiff = np.abs(al - rl)
snp   = (rl==1) & (al==1)
sv    = Ldiff > 50                       # SV cutoff = length change > 50 bp
small = (~snp) & (~sv)                    # small indels/MNPs ≤50 bp
ins, dele, mnp = al>rl, rl>al, (rl==al)&(rl>1)
# SV bins: (Ldiff>50)&(Ldiff<=100), (>100)&(<=1000), (>1000)&(<=10000), (>10000); Ldiff.max()
```

**§4 — allele-count / frequency spectrum** (carriers among called founders)
```python
# per-record carriers (AC) = column nnz of var_pa CSR  (rows=founders):

ac1   = (car==1).sum();  ac_le5 = (car<=5).sum()
af    = np.where(cal>0, car/cal, np.nan);  af_median = np.nanmedian(af)
```

**§5 — missingness** (V_pa called-mask; NF=231 founders)

miss_frac     = 1.0 - cal/231                       # per-record missing fraction
