## 1. WZA fitting bug — negative-SD floor hack (FIXED)

**Symptom:** the deg-2 clq0.9 Manhattans had points pinned at −log10 p = 300;
originally dismissed as cosmetic.

**Root cause:** `wza_script.py`'s deg-2 SNP-number correction extrapolates a
**negative predicted SD** in the sparse large-block tail (SNP >~1,150 / nonsnp
>~400 SNPs per block). A pre-existing "safety floor" clipped that to the smallest
positive SD anywhere on the curve — fabricating extreme significance independent of
the true Z (e.g. a block with raw Z=0.23 got Z_pVal=0.0). It drove **7 of the 10**
original "cross-model reproducible core" SNP blocks — the headline was mostly the bug.
This is the same failure mode `wza_investigation/RESULTS.md` diagnosed in June, recurring
at a smaller block size than assumed.

**Fix:** removed the floor hack from `wza_script.py` (negative SD → NaN, excluded from
FDR) **and** re-added a per-class SNP cap so no block is evaluated outside the
polynomial's supported domain: **snp cap=1000, nonsnp cap=350** (data-driven, 0
negative-SD in all 3 models simultaneously; larger caps re-break it). Verified 0
NaN / 0 negative-SD across all 6 model×class deg-2 outputs. Old buggy artifacts:
`clq90/wza/archive_deg2_prefloor_bug/`, `clq90/archive_prefloor_bug/`.
Frozen post-fix snapshot: `clq90/_frozen_wzafix_20260703/`.

Corrected bio1 BH q<0.05 (was snp 74/79/58, nonsnp 18/27/38 pre-fix):
kendall 63/15 · lfmm 66/24 · binomial 50/33 (snp/nonsnp). Real reproducible core
shrank from 10→ Chr1_2343 (GAPC2) + Chr4_6307 (CRK13-16), Chr3_6144 close behind.

## 2. Binomial p-value overflow → **quasi-binomial adopted (production)**

The pool binomial treats N=flowers×2 as independent draws (355 pools, only ~31
independent climates) → raw per-record p pinned at the 1e-300 floor for a huge
fraction of records; the old ad-hoc "effective-N=site" deflation left raw GIF ~8.6.

Tested 3 principled fixes (built in `../gea_newpanel/`, re-run on our clq0.9 partition
by parallel agents → `clq90/binom_fix_test/`), all with K=16 LFMM latent factors:

| method | raw GIF | BH snp/nonsnp | note |
|---|---|---|---|
| eff-N=site (old prod) | ~8.6 | 50/33 | ad-hoc, still inflated |
| beta-binomial (per-chrom ρ) | 1.9–2.0 | 43/8 | more complex |
| **quasi-binomial (per-variant φ)** | **2.6–2.8** | **35/27** | ADOPTED |
| ACER effective-N (harmonic 2·flowers, coverage) | 1.1–1.2 | 39/15 | REJECTED |

**ACER rejected** because it penalizes by sequencing *coverage*, but kMate estimates
AF from founder-haplotype deconvolution, not per-locus read counts — coverage isn't
kMate's precision bottleneck, so its near-1 GIF was well-calibrated *for the wrong
reason*. User picked **quasi-binomial** on the raw per-record Manhattan/QQ (contained,
no floor pileup, real signal tail). Now the production binomial in the clq0.9 pipeline:
- `wza_in/binomial_*` ← quasibinom `pval_quasi`; old eff-N=site archived at
  `clq90/archive_binomial_effNsite_pre_quasibinom_20260703/`.
- deliverable notebook `notebooks/binomial_fix_compare.ipynb`.
- STATUS_clq90.md decision #3 rewritten (reconciles the old "quasi-binomial backfires
  φ≈0.2" note: that was measured on already-deflated counts w/o K16; on full N with
  K16 the residual is genuinely over-dispersed φ≈4.4).

## 3. Kendall-tau inflation → **left AS-IS (no honest correction preserves signal)**

Pool-level Kendall is the worst-inflated model: GIF ~9.2, **52% of the genome at
p<0.05**, hitting the 1e-16 floor. Tested corrections (`clq90/kendall_fix_test/`,
`notebooks/kendall_fix_compare.ipynb`):

| method | GIF | max −log10p | verdict |
|---|---|---|---|
| pool-level (current) | 9.2 | 16 (floor) | inflated |
| site-collapse (31 sites) parametric | 2.26 | 2.9 | residual structure, coarse |
| MSR structure-preserving null | 1.3 | 4.0 (perm floor) | flat-ceiling, ugly |
| pool + genomic control | 1.0 | **2.4** | flattens |
| site + genomic control | 1.0 | 2.9 | flattens |

**Every honest correction flattens Kendall** — because the tall peaks *were* the
pseudoreplication (355 fake-independent pools). Once corrected, only ~31 independent
climate sites remain → very little honest per-record signal (max −log10 p ≈ 2.4–4,
0 BH-sig). Decision: keep Kendall as the raw/structure-uncorrected phase-1 reference;
**LFMM is the model to trust for calibrated climate signal** (structure-corrected via
latent factors, keeps resolution). No production change to Kendall.
