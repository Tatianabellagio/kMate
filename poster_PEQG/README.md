# PEQG 2026 poster

`poster_peqg.pdf` — poster presented at the **Population, Evolutionary, and
Quantitative Genetics (PEQG) Conference 2026**
(<https://genetics-gsa.org/peqg-2026/>).

It covers the kMate structural-variant work in this repository: pangenome
k-mer–based SV allele-frequency estimation and the GrENE-net phase-1
climate–SV genotype–environment association analysis (see
[`../analysis/grenenet_gea/`](../analysis/grenenet_gea/)).
